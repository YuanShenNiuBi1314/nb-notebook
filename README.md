# 🔥 牛逼笔记本 v1.0

把刷卷子时零散记下的知识点，自动整理成结构化的知识库，随时打印、随时手机查看。

> ✍ **作者：类人群星闪耀时 @豆包** ｜ 🏭 **北中小作坊**

## 核心能力

| 功能 | 说明 |
|---|---|
| ✨ **AI 自动分类** | 笔记保存时调用本机 OLLAMA（qwen3:8b），根据标题+内容自动归类。写"植物的维管束"和"木质部韧皮部"，会被自动归到同一个「植物结构 › 维管束」小类；写动物内容会自动开新领域。分类树会自动生长，不会重复建类 |
| 📚 **导入知识结构** | 把你的已有知识框架（JSON 格式）导入，新笔记自动挂到对应节点下 |
| 🖨 **一键打印** | 勾选任意多篇笔记 → 打印。视频/音频自动剔除并提示；图片按原始长宽比自动适配 A4，不拉伸变形 |
| 📷 **卷子提图** | 拍一张卷子照片传上来，自动检测提取其中的图片（白纸 vs 图片的对比色差描边），一键插入笔记；自动检测不理想时可手动框选 |
| 🖼 **HTML 笔记** | 笔记正文是标准 HTML，支持插图片、视频、音频、表格，所见即所得编辑 + 源码模式 |
| 📱 **手机互联** | Android APK（适配安卓 6.0+）连同一 Wi-Fi 直连电脑，手机上记笔记、AI 整理、打印都可用 |
| 📴 **离线采集** | 手机不联网也能用：拍照 / 写字 / 描边 → 导出压缩包 → 微信发电脑 → 网页「📦 手机包」一键导入整理（可 AI 分类） |

## 快速开始（电脑端）

```bat
# 1. 启动服务器（双击即可）
D:\牛逼笔记本\server\run.bat

# 启动后终端会显示：
#   本机访问   : http://127.0.0.1:8080
#   局域网访问 : http://192.168.0.2:8080   ← 手机连这个
```

2. 浏览器打开 **http://127.0.0.1:8080** 开始用。

> 首次启动若 Windows 弹防火墙提示，勾选"专用网络"并允许，否则手机连不上。

## 手机端（安卓 6.0+）

1. 把 `牛逼笔记本-v1.1.apk` 传到手机安装（允许未知来源）。
2. **两条路任选**：
   - 🌐 **连接电脑**：手机连和电脑同一个 Wi-Fi，输入电脑端显示的局域网地址（如 `192.168.0.2` / 端口 `8080`）→ 直连整理、打印。
   - 📴 **离线采集**：不需要网络。拍照 / 写字 / 描边 → 「导出压缩包」→ 选微信发送到电脑 → 电脑端网页点「📦 手机包」导入（可勾选 AI 自动整理分类）。

> 电脑端 OLLAMA 和服务器要保持运行，AI 分类才能用；离线采集不需要。

## 数据都存哪里

```
D:\牛逼笔记本\data\
├── notes\<id>\note.html   笔记正文（HTML，可备份/迁移）
├── notes\<id>\meta.json   元数据（标题、分类、时间）
└── tree.json              分类树
```

想备份就把整个 `data` 文件夹拷走。笔记就是 HTML 文件，永远不会被锁死。

## 常见问题

**Q: 端口 8080 被占用？**
改端口：编辑 `server\run.bat` 末尾加 `8081` 参数，如 `... com.nbnotebook.Main 8081`（Main 类会读取 `nb.port`，命令行传参需修改脚本：`... com.nbnotebook.Main` 后追加 `-Dnb.port=8081` 到 java 命令）。

**Q: AI 分类失败 / 提示无法连接 OLLAMA？**
确认已运行 `ollama serve`，且已 `ollama pull qwen3:8b`。服务器启动日志会显示 OLLAMA 状态。

**Q: 手机打开 App 提示连接失败？**
① 手机电脑是否同一 Wi-Fi；② 电脑防火墙是否放行；③ 地址是否输对（看电脑端启动日志里的局域网地址）；④ 电脑端服务器是否还在运行。

**Q: 自动提图没提全？**
切到「手动框选」模式，拖框圈选后点提取，更精准。

## 技术栈

- 后端：纯 JDK 17（`com.sun.net.httpserver`），零第三方依赖，`server\build.bat` 一条命令编译
- 前端：原生 HTML/CSS/JS，无框架无 CDN，离线可用
- AI：OLLAMA + qwen3:8b（分类）/ qwen3-vl:30b（预留视觉识别）
- 安卓：WebView 壳应用，Gradle + AGP 8.1.4，minSdk 23
