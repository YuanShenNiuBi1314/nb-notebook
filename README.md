# 🔥 牛逼笔记本 v1.3

把刷卷子时零散记下的知识点，自动整理成结构化的知识库，随时打印、随时手机查看。

> ✍ **作者：类人群星闪耀时 @豆包** ｜ 🏭 **北中小作坊**

## 核心能力

| 功能 | 说明 |
|---|---|
| ✨ **AI 自动分类** | 笔记保存时调用本机 OLLAMA（qwen3:8b），根据标题+梗概自动归类。写"植物的维管束"和"木质部韧皮部"，会被自动归到同一个「植物结构 › 维管束」小类；写动物内容会自动开新领域。分类树会自动生长，不会重复建类 |
| 📚 **导入知识结构** | 把你的已有知识框架（JSON 格式）导入，新笔记自动挂到对应节点下 |
| 🖨 **一键打印** | 勾选任意多篇笔记 → 打印。视频/音频自动剔除并提示；图片按原始长宽比自动适配 A4，不拉伸变形 |
| 📷 **卷子提图** | 拍一张卷子照片传上来，自动检测提取其中的图片（白纸 vs 图片的对比色差描边），一键插入笔记；自动检测不理想时可手动框选 |
| 🖼 **HTML 笔记** | 笔记正文是标准 HTML，支持插图片、视频、音频、表格，所见即所得编辑 + 源码模式 |
| 📱 **手机互联** | Android APK（适配安卓 6.0+）连同一 Wi-Fi 直连电脑，手机上记笔记、AI 整理、打印都可用 |
| ⚡ **实时采集终端** | 手机不只是离线器：连上电脑后，每拍一张 / 每条文字 / 每条描边**自动直传**到电脑「待整理区」，不再走微信中介 |
| 🔴 **红框识别** | 手绘图用红笔圈一个框，拍照后 OpenCV 自动识别红框并透视裁剪去框；识别失败自动回退整图 |
| 📦 **待整理区（缓冲区）** | 手机直传/导入的包先进待整理区，电脑端确认后才入库（可 AI 分类 + 自动起标题），避免误入 |
| 📄 **本地笔记** | 电脑端「导出包」→ 手机导入，离线也能看电脑上整理好的笔记（含图片） |
| 📴 **离线兜底** | 没连上电脑时，采集内容留本地，可导出 zip 通过微信发电脑再导入 |
| 🤖 **AI 智能** | 标题留空自动 AI 起标题；AI 归类只看标题+梗概（不读全文）；自动归入已有知识结构 |

## 快速开始（电脑端）

```bat
# 1. 启动服务器（双击即可）
D:\牛逼笔记本\server\run.bat

# 启动后终端会显示：
#   本机访问   : http://127.0.0.1:8080
#   局域网访问 : http://192.168.0.2:8080   ← 手机连这个
```

2. 浏览器打开 **http://127.0.0.1:8080** 开始用。

> 首次启动若 Windows 弹防火墙提示，勾选"专用网络"并允许，否则手机连不上。

## 手机端（安卓 6.0+）

1. 把 `牛逼笔记本-v1.3.apk` 传到手机安装（允许未知来源）。
2. App 为原生三选项卡：**📄 笔记 / ✍️ 采集 / ⚙️ 设置**。
   - 📄 **笔记**：连接电脑后按「范围 → 多级分类 → 笔记」浏览电脑上的全部笔记；点开笔记自动把里面的**音视频下载到文件管理器可见的 `Download/NBNotebook/` 文件夹**。
   - ✍️ **采集**：进入采集页后自动检测与电脑的连接。
     - **在线（正常模式）**：每拍一张 / 每条文字 / 每条描边，**自动直传**到电脑「待整理区」，列表实时显示 ✓已传；
     - **离线（兜底）**：内容留在本地，可「导出压缩包」→ 微信发电脑 → 电脑端网页「📦 手机包」导入；
     - 拍照自动做**红框识别**：手绘图用红笔圈框 → 自动裁剪去框；识别失败自动回退整图；
     - 页面上还有「📄 本地笔记」：导入电脑端「📤 导出包」的压缩包，离线浏览电脑整理好的笔记（含图片）。
   - ⚙️ **设置**：填写电脑局域网地址（如 `192.168.0.2` / 端口 `8080`）连接；连不上会自动提示，不卡界面。
3. 电脑端网页新增两个入口：
   - **📥 待整理**：手机直传/导入的内容先进这里 → 逐条确认「入库」（可勾选 AI 分类 + 自动起标题）或删除；
   - **📤 导出包**：勾选笔记 → 导出 zip（含 HTML/图片/manifest）→ 发到手机导入本地笔记。
4. 连接失败/不在同一网络时，随时用「✍️ 采集」离线模式，不依赖网络。

> 电脑端 OLLAMA 和服务器要保持运行，AI 分类/起标题才可用；离线采集不需要。

## 数据都存哪里

```
D:\牛逼笔记本\data\
├── notes\<id>\note.html   笔记正文（HTML，可备份/迁移）
├── notes\<id>\meta.json   元数据（标题、分类、时间）
└── tree.json              分类树
```

想备份就把整个 `data` 文件夹拷走。笔记就是 HTML 文件，永远不会被锁死。

## 常见问题

**Q: 端口 8080 被占用？**
改端口：编辑 `server\run.bat` 末尾加 `8081` 参数，如 `... com.nbnotebook.Main 8081`（Main 类会读取 `nb.port`，命令行传参需修改脚本：`... com.nbnotebook.Main` 后追加 `-Dnb.port=8081` 到 java 命令）。

**Q: AI 分类失败 / 提示无法连接 OLLAMA？**
确认已运行 `ollama serve`，且已 `ollama pull qwen3:8b`。服务器启动日志会显示 OLLAMA 状态。

**Q: 手机打开 App 提示连接失败？**
① 手机电脑是否同一 Wi-Fi；② 电脑防火墙是否放行；③ 地址是否输对（看电脑端启动日志里的局域网地址）；④ 电脑端服务器是否还在运行。

**Q: 自动提图没提全？**
切到「手动框选」模式，拖框圈选后点提取，更精准。

## 技术栈

- 后端：纯 JDK 17（`com.sun.net.httpserver`），零第三方依赖，`server\build.bat` 一条命令编译
- 前端：原生 HTML/CSS/JS，无框架无 CDN，离线可用
- AI：OLLAMA + qwen3:8b（分类）/ qwen3-vl:30b（预留视觉识别）
- 安卓：原生三选项卡（Java），Gradle + AGP 8.1.4，minSdk 23（安卓 6.0+），v1.3 集成 OpenCV 4.9（红框识别），仅打包 arm64-v8a + armeabi-v7a
